## Le constat : une SPA invisible pour Google

- Vite + React → un seul `index.html` avec `<div id="root"></div>`.
- Ce que voit le crawler : du HTML vide, le contenu n'arrive qu'après le JS.
- `View Source` : aucun nom, aucun projet, aucune description.

## Pourquoi le client-side rendering pose problème

- Indexation : dépend de l'exécution JS par le crawler (pas garantie, différée).
- Métadonnées : un seul `<title>`, OpenGraph statique, pas de partage propre.
- Performance perçue : écran blanc puis hydratation.

## La solution : Next.js App Router

- Rendu serveur : HTML complet livré, contenu visible immédiatement.
- `generateMetadata` par page : `title`, `description`, `hreflang`, JSON-LD.
- Server Components par défaut, `"use client"` seulement aux feuilles.

## Ce que la migration a coûté

- Repenser l'architecture en pages/segments plutôt qu'un gros composant.
- Isoler les morceaux interactifs (canvas, tilt, thème) en îlots client.
- Gérer le SSR : `localStorage`, `window`, hydratation.
